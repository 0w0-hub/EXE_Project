# After Coding

Sau mỗi task phải cập nhật:

- `tasks/active/` (đóng task hoặc cập nhật trạng thái)
- `tasks/state/current-state.md`
- `logs/progress/current.md`
- `logs/ai-agent/latest.md`
- Tạo session log mới trong `logs/ai-agent/sessions/YYYY/MM/`

Nếu có quyết định kiến trúc mới → thêm ADR trong `docs/decisions/`.
Nếu có thay đổi rule → sửa trong `rules/`.
