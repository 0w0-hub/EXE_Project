# Before Coding

Trước khi code bất kỳ task nào, đọc theo thứ tự:

1. `CLAUDE.md`
2. `rules/README.md`
3. `rules/ai-agent/before-coding.md` (file này)
4. `tasks/state/current-state.md`
5. `tasks/active/current-task.md`
6. `logs/ai-agent/latest.md`
7. Tài liệu architecture liên quan trong `docs/architecture/`
8. Rules liên quan tới module đang sửa
9. `docs/services/<service>.md` liên quan
10. Code hiện có

Không đọc toàn bộ repo một cách mù quáng — chỉ đọc phần liên quan tới task.
