# Git Rules

- Commit message ngắn, rõ mục đích (why hơn what).
- Không commit `.env` thật, ảnh test lớn, file build (`node_modules`, `target/`).
- Nhánh `main` luôn ở trạng thái build được.
- **Không đưa attribution của Claude/AI vào commit message hoặc PR** (không `Co-Authored-By: Claude...`, không footer "Generated with Claude Code"). Commit chỉ hiển thị tài khoản của user (`git config user.name`/`user.email` của user). Yêu cầu của user, ghi ngày 2026-09-16.
