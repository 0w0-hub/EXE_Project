## Problems

1. `MockAiDesignProvider.generate()`: `.formatted()` chỉ bind vào 1 trong 2 string literal nối bằng `+` (độ ưu tiên toán tử Java) → `IllegalFormatConversionException`. Phát hiện qua unit test, đã sửa (tách template ra biến riêng trước khi `.formatted()`).
2. `GlobalExceptionHandler.handleUnexpected`: không log exception, vi phạm `rules/backend/error-handling.md`, khiến bug #3 khó chẩn đoán ban đầu. Đã thêm log.
3. Flyway migration dùng `DATETIME2` cho cột Java `Instant`, nhưng Hibernate 6 + SQLServerDialect cần `DATETIMEOFFSET` → app crash lúc validate schema lúc backend start. Đã sửa migration (phải `docker compose down -v` để reset volume vì migration đã từng apply sai kiểu).
4. `docker-compose.yml` ban đầu thiếu cơ chế tạo database — SQL Server (khác Postgres/MySQL ở dự án tham khảo) không tự tạo DB qua env var. Thêm service `db-init` chạy `sqlcmd CREATE DATABASE` một lần, dùng `depends_on: condition: service_completed_successfully`.
5. Port 80 và 8081 đã bị chiếm bởi container/app khác trên máy dev → phải đổi `FRONTEND_PORT` sang 8082.
6. Khi test "chạy backend không dùng Docker", máy dev có sẵn SQL Server native (sqlservr.exe) chiếm port 1433 → kết nối `localhost:1433` từ Java process native vô tình nối nhầm vào đó, gây "Login failed" gây hiểu lầm là bug code. Xác minh bằng cách chạy container SQL Server test trên port khác (14330) — chạy đúng ngay. Đã ghi chú cảnh báo này vào `README.md`.
