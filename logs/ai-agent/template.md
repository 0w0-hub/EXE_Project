# AI Session Log Template

Copy nội dung dưới đây khi tạo session log mới tại `sessions/YYYY/MM/YYYY-MM-DD-session-N.md`.

```text
# AI Session Log

Date:
Agent:

## Task

## Context Read

## Work Done

## Files Created

## Files Modified

## Files Deleted

## Tests

## Problems

## Decisions

## Remaining Work

## Next Recommended Action
```

Không lưu toàn bộ conversation — chỉ thông tin cần thiết để agent tiếp theo hiểu tiến trình.
